# Interest Planner

A simple-interest calculator in Ghana cedis. Enter an amount, an annual rate and a number of years, and it shows the interest you would earn or pay. The answer animates each time it changes.

![HTML](https://img.shields.io/badge/HTML-E34F26?logo=html5&logoColor=white)
![CSS](https://img.shields.io/badge/CSS-1572B6?logo=css&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)

## How it works

Simple interest = principal × rate × years ÷ 100

| You enter | Example |
|---|---|
| Principal amount | 50,000 |
| Annual interest rate (%) | 7.5 |
| Duration (years) | 5 |
| **Projected interest** | **GHC 18,750.00** |

## Run it

Open `index.html` in any browser. There's nothing to install.

## Files

- `index.html`: the page and the form
- `style.css`: the layout and the animation
- `script.js`: the calculation and number formatting
